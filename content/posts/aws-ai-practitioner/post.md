"Excited to announce" that I recently passed the AWS Certified AI Practitioner exam (AIF-C01) -- scored 929/1000!

No, I didn't just repost my previous post.

This time, I decided to pair the AI Practitioner certification with the Cloud Practitioner certification I got earlier.

For my Cloud Practitioner prep, I relied on a great free practice-test site. But for the AI Practitioner exam, the same source only offered basic MCQs with no way to actually take a timed test or track scores. So I decided to make something to help myself.

What started as a quick Python script to display questions locally turned into a full quiz “app” hosted on GitHub Pages -- so I could fill up my time on the MRT (this way I could “study” on the way to my climbing gym). 

I scraped the questions into structured JSON, built a Flask version for local use, then rewrote the frontend as a static single-page app for zero-setup mobile access. Since there were only 7 practice tests, I also added a randomised 8th test that shuffles questions from all tests on every load.
