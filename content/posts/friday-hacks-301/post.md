AI code review is not security testing.
( My one-line takeaway from NUS Hackers 's Friday Hacks #301 )

Jessie Ho, introduced Vigolium, the application-security platform he is building. It combines fast native scans with agentic scans that understand the repository, test exploit paths against the live application, and return evidence-backed findings instead of a list of maybes.

I was looking to implement a DAST tool for my course project, and I'm planning to give Vigolium a proper run. 

I had also set up Terraform for AWS for that project the night before.

Justin Hoe's serverless Terraform demo made the next step clearer: the useful Terraform work starts when the configuration has to stay understandable as it grows.

Two different talks. One useful reminder: tools can speed up the work, but they do not remove the need to understand the system underneath.
