My desktop used to be a graveyard of screenshots. Hundreds of them. Each one was a mystery I had to open, decide whether to keep it or banish it to the bin. 

I made a simple Flask app you can run to help you view and sort/discard your screenshots into Kanban-style boards. 

To make sure any action is not "permanent", it uses the send2trash package (https://lnkd.in/gEKxr5RG ) to send it to your Bin.

Works with macOS, Windows, Linux, and BSD
It's small, it works, and it solved a problem I had. 

tested only with macOS - theoretically, the same package should work with Linux and Windows

github link -> https://lnkd.in/gUCstzHJ
