I wanted to know where my AI coding tokens were going, so I built a dashboard for it. 

Claude Code and OpenCodex already log every request on my machine, but their dashboards left much to be desired. 

So I made yald (Yet Another LLM Dashboard). It's a read-only dashboard that shows token usage, spend, cache efficiency, latency and quota burn in one place.

Some Insights from the last 7 days: 
My busiest hour was Sunday at 9 pm, and I used up 3.7Btokens ( rookie numbers if you compare to someone like Varick Lim who is constantly building cool stuff ). 

It started as a way to satisfy my curiosity; now it's a tab that's always open.
