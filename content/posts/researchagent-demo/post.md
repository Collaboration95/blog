On Saturday, I took ResearchAgent to the main stage at AI Tinkerers Singapore.

ResearchAgent is a research agent with a wallet. It answers from free sources first. When the missing piece sits behind a paywall, it buys that one article straight from the writer, inside a budget you set, then checks every promise the writer made.

The live demo ran on Google Cloud Run and placed in the top three Cloud Run demos of the night, so it came home with US$100 in credits.

Huge thanks to Joe Heitzeberg , Son Le , Jake Laes for running a great event and Lisa Shen from Google Cloud Run too , her Cityscape Agent demo (an ADK agent on Cloud Run, a Maps-grounded MCP server and Nano Banana drawing the city) was simple but demonstrated Google Cloud Run's utility. 

I like analysing things, so I turned the build itself into a page of charts: 39 days, 248 commits, 75 pull requests, 422 prompts to two coding agents and 2.3 billion tokens, 97% of them context the agents re-read.

 My favourite chart is a single night: 23 pull requests between 1 am and 3:19 am.
