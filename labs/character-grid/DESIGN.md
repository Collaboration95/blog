# character-grid

**Idea:** the site is a typeset RFC. Every line break is decided at build time, so nothing reflows in the browser.

**System:** one cell is 3 wide by 7 high units (Courier Prime advance 0.6em, line-height 1.4em). Text, images, captions and page furniture all sit on whole cells. Image height is a whole number of lines and width a whole number of columns. The width is the decision, so right edges stay flush; the height rounds up and at most 0.9 of a line of paper sits under the picture. Nothing is cropped or stretched (`object-fit: contain` inside an exact box).
Two sheets are composed, 80 columns (>= 640px) and 42 columns (phone), both kept in one text stream as `<br class="d|m">`. A sheet is 58 lines on desktop and 37 on phone.

**Type:** Courier Prime, cell-normalised (`fonts/courier-prime-cell-{400,700}.woff2`, 30 KB total). Size is `--c / .5996`. `--c` is `min(10.2px, 100vw/84)` on desktop and `100vw/42` on phone. Bold is used for titles, headings and indexed numbers.
**Colour:** ink `#14161b`, paper `#f4f5f2`, ground `#dcdfd9`. One ink, no accent.
**Grid:** desktop text column x=7, width 69, furniture x=4, width 72. Phone text x=4, width 37, furniture x=1, width 40.

**Details I like:**
- Running header and footer on every sheet (site name and kind, no numbers), with `^L` form-feed marks between sheets.
- Dot leaders (index openings trailing off, long-post contents) land on even columns, so they align down the page.
- Each paragraph number in the margin is its own anchor, and `:target` marks the paragraph with a rule and an inverted number.
- Figure captions read `Fig. 2 (37x12). alt`, giving the cell size. Each figure opens full size through a `:target` plate with no JS.
- Spaces that end a line are hidden per layout, so the phone sheet never scrolls sideways.

**Authoring:** optional `placements/<post-id>.md`. A line is `words before [[name mode width +dx | phone mode width +dx]] words after`.
Example: `Here is what 18 hours cost. [[01 right 40 | wide 37]] The night before`.
Modes are `right`, `left`, `wide`, `full`, `bleed` and `at`. Add `nocap` to drop the caption. Two `wide` figures on one anchor share a row (`wide 33`, `wide 33 +36`). `~ 5-7 indent 2 d` sets a paragraph option (`tight 1`; `wait 1` holds a paragraph behind its pictures), and `== phrase` bolds a number and indexes it. `@@ name d` ... `@@` draws an ascii figure, always aria-hidden; `{.33}` in one is a mark narrower than a cell. With no file, the auto rules place images inside the text at sentence ends.

**Figure rules:** a clear row above and below every figure. Figures keep their order. A side figure waits for 2 rows of full-measure text after the last figure, and a paragraph never opens in the last 2 rows beside one, so text always returns to the full measure. Auto figures only hang right, so the left edge never moves; `left` is hand-only and leaves a 4-cell gutter for the paragraph number. Nothing lands after the end matter. In a project each post opens a new sheet, so its hand placement holds.

**Hand-placed:** `commons-agent-logs` (grin beside "Plenty broke.", plus an index of its numbers), `lorong-speech-embeddings` and both other image posts in The Commons (each picture at the sentence it shows). `apple-health-import` draws time to scale: 1 column is 1 minute on the phone, 30 seconds on the wide sheet. Rules run heavy for elapsed, light for what was saved, and 9.77 seconds is a speck narrower than a cell.

**Transfers:** paragraph anchors, the `Fig. n (WxH)` caption, `c. Mon YYYY` dates, and the project/Part-n-of-m furniture. **Only works here:** the whole compositor, the cell snapping, and mono-only layout.

**Weakest:** the share card (`card.mjs`) is a 1x1 placeholder PNG, so text-only posts have a poor `og:image`. On the phone a figure that misses the bottom of a sheet waits for the next one, so a few auto-placed posts still end with a picture after the last sentence, and a sheet can end short. One anchor has to serve both sheets, so a pair on the wide sheet is a stack on the phone. Bold now also marks indexed numbers, a small break from "titles and headings only".

**Revision (Guru's review):** the site name is `data.site` everywhere (`data.author` only in `<meta name="author">`). No totals, sheet or page numbers, or LinkedIn link. The index is every post, newest first, as one entry (label and date, first image whole, opening trailing off in a dot leader); a project post carries `The Commons · 2 of 4` linking to the project page. Project pages are the title, its `line`, then each post oldest first as the same entry, linking out; no full text. The long-post contents ends each line with the number of the paragraph that follows the heading.
**Series rail:** `tools/series.mjs` `railHTML` sits after `<main>` in `div#series`; `style.css` is now generated by `build.mjs` as `RAIL_CSS` + `style.src.css` (edit the latter). From 1100px a fixed rail in the left margin: dashes are whole cells (1 to 6), the current one heavy, a hard-shadowed paper preview on hover or focus. Below that it is a paper sheet after the last page: `Series: The Commons  3 of 4`, then a numbered list set on whole lines (each row 2 lines tall for tapping). On a phone the header row also reads `The Commons · 3 of 4` (links to the project page), so the series shows on the first screen; the list is at the end.
